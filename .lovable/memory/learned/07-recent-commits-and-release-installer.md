## 2. Release-Pinned Installer Architecture

Installers distributed via GitHub Releases must be strictly pinned to their exact release tag:
- Stamp contains: Tag, Repo, Built date, Commit SHA, Builder, Asset URL.
- Rejects unstamped invocations, `/releases/latest/` URLs, and forbidden flags (`--branch`, `--version`, `--list-versions`, `--no-latest=false`).
- Hard-fails with exit 1 if release tag does not exist.
