# Spec Authoring Skill

Follows `02-spec/05-spec-authoring-guide/` standards:

1. **Folder Naming:** `NN-kebab-case/` with zero collisions.
2. **Mandatory Files:**
   - `00-overview.md` (Module metadata, file inventory table, cross-references)
   - `99-consistency-report.md` (Health score, link validation, naming check)
3. **Recommended Files:**
   - `97-acceptance-criteria.md` (Numbered, measurable testable criteria)
   - `98-changelog.md` (Chronological record)
4. **Health Score Criteria:**
   - `00-overview.md` present (25%)
   - `99-consistency-report.md` present (25%)
   - Lowercase kebab-case naming (25%)
   - Unique numeric sequence prefixes (25%)
