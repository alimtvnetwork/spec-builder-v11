# Spec-Only Repository Constraint

> **Source:** `context-for-ai.md`, `readme.md`, `.lovable/memories/constraints/01-no-code-policy.md`  
> **Scope:** Entire Repository

---

## Non-Negotiable Constraint

1. **NO APPLICATION CODE:** Do not implement application code (Go/PHP/Rust/Python) in this repository.
2. **SPECS ONLY:** Only write specifications, error codes, consistency reports, audit documents, and planning files.
3. **NO IMPLEMENTATION PROPOSALS:** Do not suggest "implement X" as a next step. Suggest spec improvements, audits, and consistency checks.
4. **EXCEPTION:** The only runtime code permitted in this repository is the Health Dashboard under `src/`.
