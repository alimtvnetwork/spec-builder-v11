# Upload Scripts — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Script Operations

- [ ] Upload script pushes plugin files to WordPress sites via Riseup Asia Uploader API
- [ ] Authentication handles API key management and rotation
- [ ] File selection supports include/exclude patterns for deployment

## AC-02: Reliability

- [ ] Retry logic handles network timeouts and transient API failures
- [ ] Dry-run mode previews changes without executing uploads
- [ ] Logging captures upload progress, file counts, and error details
