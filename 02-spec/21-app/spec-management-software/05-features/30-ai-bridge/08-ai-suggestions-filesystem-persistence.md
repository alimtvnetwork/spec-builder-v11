## 1. Overview

AI-generated suggestions within the specification management software are persisted to the filesystem as Markdown files. This ensures suggestions remain accessible for future reference, can be version-controlled, and are discoverable across development sessions.

## 3. File Naming Convention

### 3.1 Format

```
{YYYYMMDD}-{HHMMSS}-{SuggestionId}.md
```

### 3.2 Components

| Component | Format | Example | Description |
|-----------|--------|---------|-------------|
| Date | YYYYMMDD | 20260204 | Date created |
| Time | HHMMSS | 103045 | Time created (24h) |
| Suggestion ID | SNNN | S001 | Formatted suggestion ID |

### 3.3 Examples

```
20260204-103045-S001.md  # Feb 4, 2026, 10:30:45 AM, Suggestion #1
20260204-143022-S042.md  # Feb 4, 2026, 2:30:22 PM, Suggestion #42
20260205-091500-S100.md  # Feb 5, 2026, 9:15:00 AM, Suggestion #100
```

## 4. Suggestion File Template

Each suggestion is saved as a Markdown file:

```markdown
# Suggestion: {Title}

**ID:** {SuggestionId}  
**Type:** {Actionable | Informational}  
**Priority:** {Low | Medium | High}  
**Status:** {Open | Accepted | Dismissed}  
**Created:** {ISO DateTime}  
**Module:** {Chat | Blog | Code | Faq | Paragraph}

---

## Description

{Detailed description of the suggestion}

---

## Context

**Session:** {SessionId}  
**Company:** {CompanySlug}  
**Related Revision:** {RevisionId or N/A}

---

## Metadata

```json
{
  "SourcePrompt": "{Original user prompt that triggered this}",
  "RelatedFiles": [],
  "Tags": []
}
```

---

## History

| Date | Event | Details |
|------|-------|---------|
| {Created} | Created | Generated by AI |
```

This folder contains suggestions automatically generated by the AI system.

## File Naming

Files follow the pattern: `{YYYYMMDD}-{HHMMSS}-{SuggestionId}.md`

Example: `20260204-103045-S001.md`

## Generation Source

Suggestions are generated during:
- Chat sessions
- Blog post generation
- Code generation tasks
- FAQ generation
- Paragraph generation

## Synchronization

These files are synchronized with the database registry at:
`data/{app}/rag/suggestions-registry.db`

Do not manually modify suggestion IDs or create files with conflicting IDs.

## Cleanup

Old suggestions (>30 days, status=Dismissed) may be auto-archived.
```

## 7. Persistence Logic

### 7.1 Save Suggestion to Filesystem

```go
func SaveSuggestionToFilesystem(suggestion Suggestion) error {
    // Format filename
    timestamp := suggestion.CreatedAt.Format("20060102-150405")
    filename := fmt.Sprintf("%s-%s.md", timestamp, FormatSuggestionId(suggestion.Id))
    
    // Build path
    dir := ".ai-memory/memories/suggestions/ai-generated"
    if err := pathutil.EnsureDir(dir); err != nil {
        return err
    }
    filepath := path.Join(dir, filename)
    
    // Generate markdown content
    content := generateSuggestionMarkdown(suggestion)
    
    // Write file
    return pathutil.WriteFile(filepath, []byte(content), 0644)
}

func generateSuggestionMarkdown(s Suggestion) string {
    var buf bytes.Buffer
    
    buf.WriteString(fmt.Sprintf("# Suggestion: %s\n\n", s.Title))
    buf.WriteString(fmt.Sprintf("**ID:** %s  \n", FormatSuggestionId(s.Id)))
    buf.WriteString(fmt.Sprintf("**Type:** %s  \n", s.Type))
    buf.WriteString(fmt.Sprintf("**Priority:** %s  \n", s.Priority))
    buf.WriteString(fmt.Sprintf("**Status:** %s  \n", s.Status))
    buf.WriteString(fmt.Sprintf("**Created:** %s  \n", s.CreatedAt.Format(time.RFC3339)))
    buf.WriteString(fmt.Sprintf("**Module:** %s\n\n", s.Module))
    
    buf.WriteString("---\n\n## Description\n\n")
    buf.WriteString(s.Description)
    buf.WriteString("\n\n---\n\n## Context\n\n")
    buf.WriteString(fmt.Sprintf("**Session:** %s  \n", s.SessionId))
    buf.WriteString(fmt.Sprintf("**Company:** %s  \n", s.Company))
    
    if s.RelatedRevision > 0 {
        buf.WriteString(fmt.Sprintf("**Related Revision:** %d\n", s.RelatedRevision))
    } else {
        buf.WriteString("**Related Revision:** N/A\n")
    }
    
    buf.WriteString("\n---\n\n## Metadata\n\n```json\n")
    metadata, _ := json.MarshalIndent(s.Metadata, "", "  ")
    buf.Write(metadata)
    buf.WriteString("\n```\n\n---\n\n## History\n\n")
    buf.WriteString("| Date | Event | Details |\n")
    buf.WriteString("|------|-------|--------|\n")
    buf.WriteString(fmt.Sprintf("| %s | Created | Generated by AI |\n", 
        s.CreatedAt.Format("2006-01-02T15:04:05Z")))
    
    return buf.String()
}
```

### 7.2 Update Suggestion File

When status changes:

```go
func UpdateSuggestionFile(suggestion Suggestion) error {
    // Find existing file by searching for matching ID
    files, err := filepath.Glob(".ai-memory/memories/suggestions/ai-generated/*-" + 
        FormatSuggestionId(suggestion.Id) + ".md")
    if err != nil || len(files) == 0 {
        return apperror.New(
            ErrSuggestionNotFound,
            "suggestion file not found: "+FormatSuggestionId(suggestion.Id),
        )
    }
    
    // Read existing file
    existing, err := pathutil.ReadFile(files[0])
    if err != nil {
        return err
    }
    
    // Update status and append to history
    updated := updateStatusInMarkdown(string(existing), suggestion.Status)
    updated = appendToHistory(updated, time.Now(), "Status Updated", 
        fmt.Sprintf("Changed to %s", suggestion.Status))
    
    return pathutil.WriteFile(files[0], []byte(updated), 0644)
}
```
