## Frontend-Specific Codes

### 1xxx - Validation Errors

| Code | Constant | Description |
|------|----------|-------------|
| 1001 | `ErrValidationRequired` | Required field is empty |
| 1002 | `ErrValidationFormat` | Invalid format (email, URL, etc.) |
| 1003 | `ErrValidationRange` | Value out of allowed range |
| 1004 | `ErrValidationLength` | String length violation |
| 1005 | `ErrValidationType` | Type mismatch |
| 1010 | `ErrValidationForm` | Generic form validation failure |

### 5xxx - Business Logic (Frontend)

| Code | Constant | Description |
|------|----------|-------------|
| 5100 | `ErrUiState` | Invalid UI state transition |
| 5101 | `ErrUiNavigation` | Navigation blocked (unsaved changes) |
| 5102 | `ErrUiSelection` | Invalid selection state |
| 5103 | `ErrUiClipboard` | Clipboard operation failed |

## Error Code TypeScript Definition

```typescript
// src/lib/errors/codes.ts

export const ERROR_CODES = {
  // Validation (1xxx)
  VALIDATION_REQUIRED: 1001,
  VALIDATION_FORMAT: 1002,
  VALIDATION_RANGE: 1003,
  VALIDATION_LENGTH: 1004,
  VALIDATION_TYPE: 1005,
  VALIDATION_FORM: 1010,
  
  // UI State (5xxx)
  UI_STATE: 5100,
  UI_NAVIGATION: 5101,
  UI_SELECTION: 5102,
  UI_CLIPBOARD: 5103,
} as const;

export type ErrorCode = typeof ERROR_CODES[keyof typeof ERROR_CODES];
```

## Usage Examples

### Form Validation

```typescript
import { ERROR_CODES } from '@/lib/errors/codes';
import { AppError } from '@/lib/errors/AppError';

function validateEmail(email: string): void {
  if (!email) {
    throw new AppError(
      ERROR_CODES.VALIDATION_REQUIRED,
      'Email is required',
      { field: 'email' }
    );
  }
  
  if (!email.includes('@')) {
    throw new AppError(
      ERROR_CODES.VALIDATION_FORMAT,
      'Invalid email format',
      { field: 'email', value: email }
    );
  }
}
```

### UI State Error

```typescript
if (hasUnsavedChanges && !confirmDiscard) {
  throw new AppError(
    ERROR_CODES.UI_NAVIGATION,
    'You have unsaved changes',
    { 
      route: targetRoute,
      unsavedFields: ['content', 'title']
    }
  );
}
```
