# WordPress SEO Publish CLI — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Publishing

- [ ] Content publishing pushes articles to WordPress via REST API
- [ ] SEO metadata (title, description, schema) is set on publish
- [ ] Image optimization and upload handles featured images and inline media

## AC-02: SEO Features

- [ ] Yoast SEO integration sets focus keywords and readability targets
- [ ] Internal linking suggestions reference existing site content
- [ ] Sitemap regeneration triggers after content publication
