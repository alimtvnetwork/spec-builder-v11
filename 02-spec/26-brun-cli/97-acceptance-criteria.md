# BRun CLI — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Build Operations

- [ ] Build runner executes configured build pipelines for Go and TypeScript projects
- [ ] Error handling reports build failures with structured error codes
- [ ] Output artifacts are placed in configured deployment directories

## AC-02: Deployment

- [ ] Deployment pipeline supports staging and production targets
- [ ] PowerShell integration follows the standard run.ps1 template
- [ ] Build logs capture stdout/stderr with timestamps
