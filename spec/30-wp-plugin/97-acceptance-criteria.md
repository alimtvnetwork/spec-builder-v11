# WordPress Plugin — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Exam Manager

- [ ] Admin backend supports exam CRUD with hierarchical sub-exams
- [ ] Participant management handles registration, submission, and grading
- [ ] Frontend displays exam content with prerequisite enforcement

## AC-02: Link Manager

- [ ] Internal linking service suggests and manages cross-page links
- [ ] SEO integration validates link attributes and anchor text
- [ ] Shared constants enforce consistent enum values across modules

## AC-03: Plugin Infrastructure

- [ ] Plugin structure follows WordPress coding standards and hooks API
- [ ] RBAC system controls admin, editor, and participant permissions
- [ ] Database schema uses proper WordPress table prefixes and migrations
