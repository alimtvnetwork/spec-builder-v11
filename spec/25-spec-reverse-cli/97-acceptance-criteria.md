# Spec Reverse CLI — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Reverse Engineering

- [ ] Code scanning parses Go and TypeScript source files into structural models
- [ ] Spec generation produces markdown specification files from code analysis
- [ ] Output follows the project's spec folder structure and naming conventions

## AC-02: Accuracy

- [ ] Generated specs include function signatures, types, and relationships
- [ ] Cross-references between generated specs use correct relative paths
- [ ] Re-running on unchanged code produces identical output (deterministic)
