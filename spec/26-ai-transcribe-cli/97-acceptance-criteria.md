# AI Transcribe CLI — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Transcription

- [ ] Audio input supports WAV, MP3, and M4A formats
- [ ] Transcription uses AI models with configurable accuracy/speed tradeoff
- [ ] Output includes timestamped text segments with speaker detection

## AC-02: Deployment

- [ ] PowerShell deployment follows the standard run.ps1 template
- [ ] Configuration supports multiple transcription provider backends
- [ ] Error handling covers audio format issues, API failures, and quota limits
