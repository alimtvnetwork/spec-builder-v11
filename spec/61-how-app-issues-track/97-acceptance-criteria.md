# Issue Tracking & Remediation — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Issue Documentation

- [ ] Every issue follows the mandatory write-up template (summary, root cause, fix, prevention)
- [ ] Issues include iteration history documenting failed approaches
- [ ] Prevention rules and acceptance criteria are defined for non-regression

## AC-02: Process Compliance

- [ ] Affected specifications are updated with 'Known pitfalls' sections
- [ ] Memory files are updated with prevention rules after each resolution
- [ ] Done checklist is completed before marking an issue as resolved
