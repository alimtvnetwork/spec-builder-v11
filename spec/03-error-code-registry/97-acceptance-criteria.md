# Error Code Registry — Acceptance Criteria

**Version:** 1.0.0  
**Last Updated:** 2026-03-20

---

## AC-01: Registry Management

- [ ] Error codes follow assigned ranges per project (SM: 2000–2999, GS: 7000–7919, etc.)
- [ ] No error code collisions exist between projects
- [ ] Registry schema validates all error code entries

## AC-02: Integration

- [ ] CLI tools reference error codes from the central registry
- [ ] Error codes include severity, category, and resolution guidance
- [ ] Overlap validator script detects and reports range conflicts
